# 盛欣網絡股份有限公司 (SX / Shenxin Network Group)
## 《鬥陣歡樂城》代理商房卡分銷與俱樂部營運 內部控制九大交易循環四階全景手冊

本手冊專門針對盛欣網絡旗下旗艦休閒競技棋牌手遊**《鬥陣歡樂城》**之核心商業運營模式量身重構。全面遵循臺灣證券交易所 (TWSE)、證券櫃檯買賣中心 (TPEx)《內部控制制度有效性判斷參考項目》、金管會《公開發行公司建立內部控制制度處理準則》、國際 COSO 內部控制架構、ISO 27001 資安與 ISO 42001 人工智慧治理規範。

### ✨ 全站靈動微動態與視覺特效體系 (Dynamic Motion & Ambient Effects)

為營造身歷其境的東方茶館與俠客牌桌氛圍，網頁全面注入現代高品質動態交互：

1. **茶香靈動金星粒子畫布 (Ambient Canvas 60fps)**：輕量級 GPU 加速漂浮粒子，緩緩升騰淡出，營造溫潤深邃的東方空間感。
2. **頂部捲動閱讀進度條 (Scroll Progress Bar)**：暖金三色漸層指示線，即時反饋整份手冊閱覽進度（0%～100%）。
3. **「鬥陣」鎏金 Logo 呼吸光暈 (Logo Shimmer Glow)**：3D 官方圖標定期散發溫潤金屬光澤；右側 AI 專題頁籤帶有金橘雙色脈衝光圈。
4. **卡片視差平滑揭露 (Scroll Reveal)**：滾動進入視口時優雅平滑淡入滑行；Bento Grid 關鍵成效數字自動動態累加遞增。
5. **流程圖步進卡片 3D 微浮動與呼吸脈衝**：懸停步驟節點產生 3D 浮起與發光，步驟編號節奏跳動。
6. **硃砂印章落款點擊反饋 (Seal Stamp Impact)**：點擊官方審定印章呈現真實落款蓋印震動動畫。
7. **一鍵火箭回到頂端按鈕**：滾動超過 320px 自動平滑浮現，附帶彈性跳動回頂效果。

### 🎴《鬥陣歡樂城》商業模式深度解構：代理商與俱樂部房卡進銷體系

《鬥陣歡樂城》以好友/俱樂部開桌（麻將、撲克、地方棋牌）為核心玩法，核心變現邏輯為：

```
   [ 盛欣網絡 官方平台 ]
            │ 批發進卡 (1~3折階梯折讓 / 預收房卡款項)
            ▼
   [ 一級總代理 / 俱樂部會長 ] (由【推廣部門】招募、徵信、簽約與授權)
            │
            ├────> [ 二級代理 / 社群推廣員 ]
            │               │
            ▼               ▼
   [ 俱樂部會員 / 終端玩家 ] (消耗房卡開桌 ➔ 由【營運部門】後台 AMS 監控)
            │
            ▼ 遊戲開桌即時扣卡 (Server 扣除桌次服務費)
   [ IFRS 15 營收結轉 ] (實際開桌消耗轉列收入，未耗用續列合約負債)
```

### 📊 手遊代理商模式九大交易循環涵蓋範圍

1. **CYCLE-01 銷貨及收款循環**：代理商批發進卡申請、階梯折扣審批、財務核款開立發票、營運部 AMS 系統房卡劃撥、俱樂部開桌消耗與 IFRS 15 遞延收入結轉、嚴禁涉賭合規切結。
2. **CYCLE-02 採購及付款循環**：推廣線下賽事活動採購、贈品禮券採購、KOL/主播推廣合作、棋牌 2D/3D 美術與方言語音包 (CV) 外包著作權買斷、代理商月度佣金返點核銷 (三單比對 PO＝GRN＝Invoice)。
3. **CYCLE-03 研發製作與版本交付循環**：取代傳統工廠生產！棋牌玩法設計 (GDD)、隨機洗牌演算法 (RNG) 國際認證 (GLI-19)、AMS 代理後台研發、防夥牌 (Anti-Collusion) 模組、QA 弱網壓測與版本零停機發布。
4. **CYCLE-04 薪工循環**：推廣人員業務提成 (依代理商實際入帳淨流水計算)、營運客服 24/7 輪班與大夜津貼、研發人員每週專案工時 (Timesheet) 資本化分攤、全員簽署智財讓與及保密合約 (NDA)、離職當日即刻停用 AMS/Git 權限。
5. **CYCLE-05 融資循環**：代理商加盟履約保證金專戶存管與無息退還、預收房卡資金調度、銀行融資借款動撥、公司大小印分離保管用印與每月非出納人員編制銀行存款調節表。
6. **CYCLE-06 投資循環**：地方棋牌研發團隊收購 (Studio M&A)、優質大型俱樂部扶持基金投資、原始碼實地查核 (Code DD)、外部專家公允價值評價、董事會決議與期末商譽無形資產減損測試。
7. **CYCLE-07 固定資產循環**：研發高階工作站 (Mac Studio/PC)、推廣外出展示用平板 (Device Farm) 借還專人管制、年度 100% 實體條碼盤點、汰舊電腦硬碟實體消磁破碎除帳。
8. **CYCLE-08 研究發展循環**：新棋牌模組綠燈立項 (Greenlight Pitch)、「鬥陣歡樂城」商標全球註冊、核心發牌專利申請、不可篡改電子研發日誌、開源代碼 (SBOM) 阻斷 GPL 感染協議、IAS 38 研發費用資本化。
9. **CYCLE-09 電腦化資訊系統處理循環 (ITGC & GameOps)**：AMS 代理系統特權帳號雙因子 (MFA) 認證、防內部私自印卡/虛增房卡 (Card Injection) 審計日誌、Kubernetes (GKE) 跨區容器化部署、反外掛記憶體修改、抗 1Tbps+ DDoS 流量清洗與資料庫 100% Zero Outage 災備。
